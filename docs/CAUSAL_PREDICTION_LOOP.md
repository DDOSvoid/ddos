# 公告利多预测的因果闭环

最后更新：2026-08-24

## 结论

分类和预测是两个任务：分类回答“这是什么事件”，预测回答“在可交易时点之后，它是否带来
正超额收益”。当前规则评分只能作为候选特征，不能称为经过历史准确率验证的利多程度。

正式预测由大模型/文本、表格和LSTM时间序列三个专家分支在统一的1/3/5日目标下输出，融合层
汇总三路折外或前向预测。大模型事实提取只是文本分支的上游语义步骤，不等于已经完成收益预测。

## 默认评价口径

- 信息截止：程序当次运行时已经公开的标题、正文和历史记忆。
- 因公告只有发布日期、没有可靠分钟时间，统一保守地从公告后的下一交易日开盘执行。
- 观察期：1、3、5 个交易日，分别建立预测，不互相替代。
- 实际结果：股票从次日开盘到观察期末收盘的收益，减去同期沪深300收益。
- 实际方向：超额收益大于 0 为利多，小于 0 为利空，等于 0 为中性。
- 预测命中：冻结的预测方向与实际方向一致。
- 最终预测：冻结融合模型输出的正超额收益概率、预期超额收益和风险区间。
- 历史可靠性：对应预测器版本和记忆组历史命中率的 95% Wilson 下界；不混入规则主观分或 AI 自报置信度。
- 最少样本：同一记忆组至少 20 条已到期预测，否则显示“样本不足”，只能作为前向研究结果，不能进入正式利多榜。

## 每日顺序

1. 抓取并分类当次可见公告；拒判公告不进入利多预测。
2. 三个专家分支分别输出方向概率、预期收益、风险和可用性；融合器生成最终结果并立即写入不可变
   `impact_predictions`，同时冻结文本哈希、数据截止点、组件/融合版本、记忆截止点和所用历史准确率。
3. 利多榜读取冻结融合结果，并只从 `prediction_memories` 读取预测时点以前已经到期的历史可靠性；
   Wilson下界用于放行和可靠性展示，不能替代或事后改写当时的融合预测。
4. 行情到达 1/3/5 日观察期后，向 `prediction_outcomes` 追加真实超额收益，不能回写预测。
5. 错误预测写入 `prediction_reflections`，记录错误类型、原因和可复用经验；反思只能影响下一版
   预测器或未来日期，不能修改过去预测。
6. 用新增已到期结果生成带 `as_of` 和来源哈希的新记忆快照，旧快照永久保留。

## 防未来数据规则

- `memory_cutoff <= prediction.as_of`。
- 构建记忆时只接受 `outcome_available_at <= memory.as_of` 的记录。
- 同一公告、预测器版本和观察期只允许一个预测；修改逻辑必须产生新版本，不能覆盖。
- 回测按日期向前滚动；任何日期的阈值、样本统计和反思只能来自更早且已到期的数据。
- 最新 5 个交易日的 5 日结果自然未到期，必须保持 pending，不能用短期数据代填。
- AI 候选人工标注、随机数据和合成数据都不能作为市场结果。

历史公告可以从真实行情生成 `announcement_market_targets` 训练目标，但它们不代表程序当时真的
做过预测，不能拿来宣称历史准确率。历史准确率只能来自严格按日期滚动重放产生的冻结影子预测，
或今后每日实时写入 `impact_predictions` 的预测。

## AI 何时进入

先让大模型完成有逐字证据的事实提取，并通过独立人工核验；再用冻结事实建立文本分支预测头。
文本、表格和LSTM分支分别做滚动样本外验证，只有通过各自门槛的组件才能进入融合。未通过版本只
做影子预测。

真实结果成熟后，大模型可以读取当时冻结的预测、证据和结果，生成结构化正确/错误反思。反思只
进入未来日期的检索Memory或下一离线版本，不能修改过去预测。第一阶段称为带延迟结果的监督反馈
闭环；在积累足够不可变轨迹并具备离线评估以前，不把它宣称为在线强化学习。
