# 时间序列 LSTM v1 训练期 OOF 报告

最后更新：2026-08-24

结论：`KEEP_RESEARCH_ONLY_DO_NOT_FREEZE`

官方测试读取：0

## 1. 研究问题

本轮只回答：小容量单层 LSTM 在完全相同的训练样本和 expanding-window folds 上，是否同时满足绝对预测门槛，并稳定优于已固定的直接序列 Logistic/Ridge 基线。

本轮不读取表格模型 OOF。根据预登记顺序，只有 LSTM 先通过绝对门槛和简单序列增量门槛，才允许进入表格增量比较。本轮没有候选取得该资格。

## 2. 固定合同

- 合同：`causal-timeseries-lstm-daily-v1`
- 合同 SHA256：`ce3f577687d50162f15a1e9e7a43f8c6989a8793c195480882fc7471299cbc5f`
- 样本：20日与60日在每个期限使用完全相同的公司日身份和 folds。
- 候选：lookback `{20, 60}` × hidden size `{16, 32}` × horizon `{1, 3, 5}`，共12个候选。
- 架构：单层、单向 LSTM，外部 dropout 0.10，无 attention、Transformer 或第二层。
- outer folds：固定3个 expanding-window folds。
- inner split：每个 outer-fold 训练段按唯一发布日期划分为70%模型拟合、15%早停、15%校准；每段继续执行 outcome 成熟过滤。
- 预处理：只在 inner model-fit 段拟合中位数填补和标准化。
- 优化：CPU确定性 AdamW、固定种子、batch 256、最大50 epochs、patience 5、梯度裁剪1.0。
- 概率校准：inner calibration 段温度缩放；若该段 Brier 恶化则回退 identity。
- 区间校准：inner calibration 段 split-conformal interval expansion，目标覆盖80%。
- 禁止早停后使用 early-stop 或 calibration 数据重拟合权重。

## 4. 失败原因

- 12个候选均未通过完整绝对门槛。
- 所有候选的利多命中 Wilson 95% 下界均低于50%。
- 所有候选的收益MAE均未优于fold-train收益中位数基线。
- 12个候选的绝对区间诊断全部失败。
- 只有20日-h32-5日的扣费收益CI下界为正，但其Brier、Wilson、fold稳定性、收益MAE和绝对区间门槛失败。
- 20日-h16-1日的Brier仅轻微优于常数，但Wilson、成本收益、收益MAE和区间门槛失败。
- 60日-h32-5日取得最高AUC 0.5350，但Brier仍差于常数，不能按单一排序指标放行。
- 7/12个候选稳定优于匹配的简单序列基线，但仍未优于常数/中位数等绝对基线。
- 温度缩放在真实outer OOF上仅3/12个候选未恶化Brier；校准不能挽救缺乏稳定绝对信号的问题。
