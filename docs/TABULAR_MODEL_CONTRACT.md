# 表格收益/风险模型合同

表格模型代码、数据与模型产物分别限定在：

- `src/prediction/tabular/`
- `data/tabular/`
- `models/tabular/`

机器合同为 `config/tabular_model.yaml`，并同时引用严格时间切分合同和因果开发合同。当前 v1 的模型样本固定为日频。允许下载训练期15分钟行情，但只能聚合成公告前完整交易日的滞后特征；分钟级预测必须等待权威公告时间，并创建新的 timing 合同版本。

训练和模型选择只能读取 2023–2024，通过三个 expanding-window folds 前向推进。2025-01-01 至 2025-08-19 的官方测试在模型、特征、预处理和超参数冻结后只读取一次；2025-08-20 至年底永久隔离；2026 年以后只作前向验证。

每个宽表特征都必须登记来源、可用时间列；日行情特征还必须登记对应交易日期。验证器拒绝：

- 可用时间晚于预测时点的值；
- 与公告同日或公告之后的历史日行情；
- 目标、未来收益、未来风险、实际方向和其他结果字段；
- 任何非训练角色参与拟合或模型选择。

收益和风险标签单独存储。公告后的价格、收益、实现波动率和下行结果只允许出现在标签或评估产物中。

15分钟原始行情按来源、股票、年份写入 `data/tabular/intraday_15m/raw/`，状态文件逐块记录来源、时间戳语义、行数和SHA-256。AmazingData 的 bar 标签为区间起点，可用时间按标签加15分钟记录。源价格不复权，只允许计算单日内波动、振幅、尾盘收益和量价集中度；跨日收益继续使用既有日线复权口径。

## 与总路线图的当前对齐状态（2026-08-24）

v2的数据和输出合同已经对齐总路线图，但**输入覆盖与模型效果仍未满足**表格分支的最终要求。

- `train_v2` 保留50,802行和物理分离标签，在v1的63个输入之上增加15个估值/流动性输入，共78个模型特征；特征Schema哈希为 `c3193928866643e121d4838344e9ba43ea4538fb85d0be280f9a4a44293f99ee`。
- `daily_basic` 独立审计通过：343个请求分区中325个有数据、18个为空、151,674行；与训练快照重合的151,674个收盘价不一致数为0，18个空代码也都没有训练期日线。训练日线覆盖率为97.74%，而按模型样本严格向后匹配后的可用率为99.21%。
- 公司/行业与时点财务的训练域原始回填已完成：1,373个请求分区失败0个，原始文件、哈希、披露日期和完整版本身份审计通过。该结论只放行原始档案，不放行模型特征；行业仍缺61个代码的900个训练公司日，财务仍需证明当前供应商快照保留历史更正前值。
- 补充审计已完成：历史行业成员/分类补充后覆盖16,204/17,017训练公司日（95.22%），仍缺813日/58代码；财务修订抽样9/12组通过（收入、资产负债表、现金流各3组），但1份全扫描PDF只有CDP元数据，正文证据未解决。因此两组仍不得进入`train_v2`。
- 版本化目录 `config/tabular_feature_catalog_v2.yaml` 登记了全部78个输入的来源、单位、可用时间、观察日期、转换和缺失策略；结构化公告事实、时点财务、公司/行业三组因尚无合格时点证据而明确阻断。
- 主风险已统一为1/3/5日 `future_absolute_excess_return`，输出为 `predicted_absolute_excess_return`；实现波动率和下行结果只作辅助诊断。
- `research_v2` 在训练折内部使用时间递进Platt校准，生成148,784行 `tabular-component-oof-v2`，同时携带校准概率、预期收益、主风险、可用/拒判状态、模型版本、数据截止点和证据哈希。
- 完整v2的线性、LightGBM、CatBoost在三个期限共9个候选全部未通过强制门槛。CatBoost风险MAE虽在1/3/5日汇总优于基线，但5日未达到至少两个fold改善；因此没有可冻结模型，2025官方测试继续密封。

后续新增字段不得静默改写v2。公司/行业与时点财务的原始档案位于 `data/tabular/point_in_time_sources/`，在各自阻断项解除前不得进入 `train_v2` 或伪装成已放行输入。每个新增特征组都必须建立新目录版本，通过时间可用性审计和同样本分组消融，再生成新数据版本。详细顺序以 `docs/MODEL_DEVELOPMENT_ROADMAP.md` 阶段4为准。

行业补充证据见 `data/tabular/industry_supplement_v1/audit.report.json`；财务修订证据见 `data/tabular/financial_revision_evidence_v1/audit.report.json`。财务审计将 `free_cashflow` 作为派生字段单独标识，直接现金流字段仍需逐版本命中；CDP只负责公开公告页面/API的采集和元数据留证，不改变本合同的可用时间或特征放行规则。
## 2026-08-25 状态覆盖（以机器审计和 v3 manifest 为准）

前文关于“行业和时点财务仍 BLOCKED”的历史记录保留作审计轨迹；当前放行状态已改变：行业补充和财务修订证据审计均为 `feature_release_eligible=true` 且无 release blocker。新增特征只进入独立的 `causal-tabular-feature-catalog-v3` / `causal-tabular-train-dataset-v3`，不得改写 `train_v2`。
