# 电气设备三专家融合快速试点

本试点用于回答一个有限问题：在继续下载全 A 股 481,280 份核心公告之前，文本、表格和时序三个专家的因果 OOF 信号，经静态融合后是否产生稳定的增量排序价值。

它不是全 A 股正式模型，也不能支持跨行业泛化结论。

## 冻结范围

- 行业：`电气设备`，当前数据库训练域共343家公司、32,668份核心公告、17,211个公司日。
- 训练期：2023-01-01至2024-12-31；行情前史从2022-09-01开始。
- 横截面：八个季度各确定性等距选择12个公告日，且每个日期至少20家公司有合格公告。
- 样本：96个日期、331家公司、3,409个公司日、6,317份完整核心公告。
- 同一入选日期的所有合格公司与核心文档全部保留，避免只抽取“看起来重要”的公告而破坏当日排序横截面。
- 日期选择不读取市场收益、标签、2025官方测试区或2026前瞻区。

冻结合同是 `config/electrical_equipment_pilot_v1.yaml`，机器清单和内容哈希位于 `data/backfills/event_ranking_pilot_electrical_v1/manifest.json`。

## 数据顺序

1. 6,317份试点公告正文。
2. 200份确定性分层PDF来源审计；不下载所有PDF。
3. 343只股票和沪深300基准的完整训练日线。
4. 仅为6,317份计划内公告生成1/3/5日训练标签。
5. 343只股票的训练期`daily_basic`估值和流动性数据。
6. 343只股票的时点行业与三张财务报表原始数据。

所有阶段使用独立状态文件；原全 A 股下载断点不会被覆盖。

## 运行与查询

生成或复核冻结清单：

```powershell
.venv\Scripts\python.exe scripts\build_electrical_equipment_pilot.py
```

运行可恢复队列：

```powershell
.venv\Scripts\python.exe scripts\run_electrical_equipment_pilot_queue.py
```

查询只读进度：

```powershell
.venv\Scripts\python.exe scripts\check_electrical_equipment_pilot.py
```

## 进入下一阶段的门槛

- 三个专家全部通过时点、来源、版本和缺失/弃权完整性门槛。
- 融合只能使用各专家先前时间折的OOF输出。
- 先比较等权融合和非负静态融合；静态融合未通过前不增加动态门控复杂度。
- 融合需同时超过最好单专家与等权融合。
- Top-K扣除20bp成本后收益为正，且相对其余候选的收益差为正。
- 结果需在时间折之间保持方向稳定。

试点通过后，先在第二个异质行业复验，再决定是否恢复全 A 股下载。

## 严格样本外边界

2025官方测试区、2025隔离区与2026严格样本外区在系统冻结前均不得下载特征或标签。2026结果只能在模型、融合器和预测台账全部冻结后一次性评估。
