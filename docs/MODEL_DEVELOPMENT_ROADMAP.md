# 多模型公告预测路线图

最后更新：2026-08-24

这份文档是后续逐步实施的唯一主路线图。每完成一个阶段，都要更新状态、证据、模型版本和放行结论。任何模块未通过本阶段门槛，不得提前进入正式测试或每日利多榜。

## 已确认的系统目标

最终系统由三个独立专家分支、一个融合层和一个预测后反馈闭环组成：

| 模块 | 核心职责 | 模块内部输出 | 进入融合层的统一输出 |
|---|---|---|---|
| 大模型/文本分支 | 理解公告语义、事件角色、实体、数值、风险和不确定性 | 带逐字证据的结构化事实；后续建立独立文本预测头 | 1/3/5日正超额收益概率、预期超额收益、风险/拒判标志 |
| 表格分支 | 处理公告事实、财务、估值、公司、行业、市场等横截面和聚合特征 | 树模型及线性基线的折外预测 | 同上 |
| 时间序列分支 | 直接学习预测时点以前的价格、成交量和市场序列形态 | 小型LSTM及简单序列基线的折外预测 | 同上 |
| 融合层 | 汇总三路互补信息，产生每日最终预期 | 校准后的融合概率、收益、风险及组件贡献 | 每只股票、每个持有期的最终预测 |
| 反馈闭环 | 在真实结果成熟后记录正确/错误原因并形成可复用经验 | 不可变预测、结果、反思和版本化Memory | 只影响未来预测器，不修改历史预测 |

大模型的“事实提取”和“大模型分支的收益预测”是两个不同步骤。当前正在开发的是前者；只有事实提取通过独立准确率门槛后，才建立读取这些冻结事实的文本预测头。提取器本身始终看不到市场目标，避免把未来涨跌泄漏进语义特征。

## 统一预测目标与每日输出

三个分支可以使用不同输入和模型，但进入融合层前必须针对同一目标、同一预测时点和同一样本输出可比较的折外结果：

- 目标期限：公告后1、3、5个交易日；
- 方向目标：相对沪深300超额收益是否大于0；
- 连续目标：对应期限的预期超额收益；
- 风险目标：预测不确定性、误差尺度或风险区间；
- 可用性：模型版本、数据截止点、是否拒判/缺失以及证据哈希。

每日最终报告至少展示每只股票在1/3/5日的融合正收益概率、预期超额收益、风险、三路组件贡献、数据完整性和历史可靠性。模型自报置信度不能替代校准概率或真实历史验证。

- 一次性官方测试集：2025-01-01 至 2025-08-19。

- 前向验证集：2026-01-01 起；只验证，不训练、不调参。
- 官方测试集目前读取次数：**0**。
- 禁止随机切分。训练集内部只能做按时间向前推进的 expanding-window 验证。

## 当前默认决策时点

第一套系统固定为每日开盘前运行，逻辑时点为 Asia/Shanghai 08:30。历史数据暂时只有公告日期、没有可靠分钟级发布时间，因此历史回放采用最保守规则：

- 可以读取当时已经发布的公告原文；
- 行情只能读取 `trade_date < announcement.published_date` 的记录；
- 财务数据必须在预测时点以前已经披露，禁止使用后来更正或重述的数据；
- Memory 只能读取 `outcome_available_at <= prediction.as_of` 的历史结果；
- 当前大模型在历史阶段只能做带原文证据的客观提取，不能把自身已有知识当成历史涨跌标签。

未来如果补齐可靠的公告发布时间，可以建立新的合同版本；不得静默修改本合同。

- 训练集 89,485 条公告，正文和 PDF 覆盖均为 0。

### 阶段 6：融合模型 — 待开始

- [ ] 三个分支先对齐样本、预测时点、1/3/5日目标、校准口径和可用性标志；融合只读取各组件的 out-of-fold 预测，不读取组件训练内预测。
